To add a set: drop a folder of 12 SVGs named wK wQ wR wB wN wP bK bQ bR bB bN bP
into this directory and add an <option> for it in templates/games/game.html.
Check each set's license first - several popular sets (e.g. california, staunty) are
CC BY-NC-SA (non-commercial) and "alpha" is personal-use only.
